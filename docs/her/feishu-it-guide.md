# 飞书机器人创建操作清单（IT 部门）

本文档面向公司 IT 部门，说明如何在飞书开放平台创建一个 AI 助手机器人。

**重要：整个流程分三个阶段，IT 和部署者需要配合完成。** 原因是飞书的"长连接"事件订阅模式要求服务端先启动并连接，IT 才能在后台保存配置。

预计总耗时：约 15-20 分钟（含等待部署者启动服务的时间）。

---

## 前置条件

- 拥有飞书开放平台管理员权限（open.feishu.cn）
- 浏览器登录飞书管理员账号

---

## 阶段 A：IT 创建应用（独立完成，约 10 分钟）

### 步骤 1：创建自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn)，登录管理员账号
2. 点击左上角「创建应用」
3. 选择「自建应用」
4. 填写信息：
   - **应用名称**：公司AI助手（或任意名称，全员可见）
   - **应用描述**：公司内部 AI 智能助手
   - **应用图标**：上传一张 Logo（可选）
5. 点击「创建」

### 步骤 2：启用机器人能力

1. 进入刚创建的应用页面
2. 左侧菜单点击「添加应用能力」
3. 找到「机器人」，点击「添加」
4. 机器人名称保持默认即可

### 步骤 3：获取凭证

1. 左侧菜单点击「凭证与基础信息」
2. 记录以下两个值（**请妥善保管，不要泄露**）：
   - **App ID**：格式如 `cli_xxxxxxxxxxxxxxxxxx`
   - **App Secret**：格式如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### 步骤 4：添加权限

1. 左侧菜单点击「权限管理」→「API 权限」
2. 在右侧搜索框中逐一搜索以下权限标识，找到后点击「开通」：

**权限 1：搜索 `im:message`**

在搜索结果中找到 **"获取与发送单聊、群组消息"**（标识：`im:message`，类型：应用身份），点击「开通」。

- 用途：接收用户发给机器人的消息

**权限 2：搜索 `im:message:send_as_bot`**

在搜索结果中找到 **"以应用的身份发消息"**（标识：`im:message:send_as_bot`，类型：应用身份），点击「开通」。

- 用途：机器人回复用户消息

**权限 3：搜索 `im:resource`**

在搜索结果中找到 **"获取与上传图片或文件资源"**（标识：`im:resource`，类型：应用身份），点击「开通」。

- 用途：收发图片（AI 识图、发图等功能需要）

开通完成后，权限列表应显示 3 个已开通权限，全部为「应用身份」类型。

> **注意**：不需要开通 `im:message.p2p_msg:readonly` 等其他权限。以上 3 个权限已完全覆盖机器人的所有功能（收消息、发消息、收发图片）。

### 步骤 5：将凭证交给部署者

将以下信息通过安全渠道（当面、加密消息等）提供给部署者：

```
App ID:     cli_xxxxxxxxxxxxxxxxxx
App Secret: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**注意**：
- App Secret 等同于密码，不要通过明文邮件发送
- 不要在公开的聊天群中分享
- 建议面对面交接或使用加密工具

然后告诉部署者：**"凭证给你了，请先启动服务，启动成功后通知我，我需要回来完成一步配置。"**

---

## 阶段 B：部署者启动服务（IT 等待）

> 此阶段由部署者完成，IT 等待通知。

部署者拿到 App ID 和 App Secret 后：

1. 在 `docker/users.csv` 中添加用户信息（含飞书凭证）
2. 运行 `./start-user.sh --id=N` 启动 Docker 容器
3. 确认容器日志中出现以下内容：
   ```
   [feishu] [default] connecting Feishu WSClient...
   [feishu] [default] Feishu WSClient connected
   [ws] ws client ready
   ```
4. 通知 IT：**"服务已启动，WebSocket 已连接，你可以继续配置了。"**

---

## 阶段 C：IT 配置事件订阅 + 发布（需服务在线，约 5 分钟）

> **为什么要分两次？** 飞书的"长连接"模式要求 SDK 客户端已连接飞书服务器，才能保存配置。所以必须先启动服务（阶段 B），然后 IT 才能完成这一步。

### 步骤 6：配置事件订阅

1. 回到飞书开放平台 → 你的应用
2. 左侧菜单点击「事件与回调」→「事件配置」
3. 在「订阅方式」区域，选择 **"使用 长连接 接收事件"**（不要选"将事件发送至开发者服务器"）
4. 点击 **「保存」**

> 如果保存失败，说明部署者的服务未启动或未连接成功。请让部署者检查日志确认 `Feishu WSClient connected` 已出现。

5. 在同一页面下方，点击 **「添加事件」**
6. 搜索 `im.message.receive_v1`
7. 在结果中找到 **"接收消息 v2.0"**（标识：`im.message.receive_v1`），点击添加

> **为什么选长连接？** 长连接模式不需要公网 IP 或域名备案，服务端主动连接飞书服务器，部署在内网也能正常工作。

### 步骤 7：设置可用范围 + 发布

1. 左侧菜单点击「应用发布」→「版本管理与发布」
2. 点击「创建版本」
3. 在「可用范围」中选择：
   - **全部员工**：公司全员可使用此机器人
   - **指定部门/人员**：仅特定部门或人员可使用
4. 根据需求选择，建议先选「指定人员」进行测试，验证后再开放全员
5. 填写版本号（如 `1.0.0`）和更新说明（如"首次发布"）
6. 点击「提交发布」
7. 如果需要管理员审批，通知审批人进行审批

### 步骤 8：验证

1. 审批通过后，在飞书客户端搜索机器人名称
2. 点击机器人，应该能看到 **私聊对话框**
3. 发一条消息（如 "你好"），机器人应在几秒内回复

如果搜索到了机器人但 **没有对话框**：
- 确认步骤 6 的事件订阅已保存成功
- 确认步骤 7 已创建新版本并发布（事件订阅配置需要包含在已发布的版本中）

---

## 完成

机器人上线后，IT 部门的创建工作就完成了。

---

## 后续维护

| 场景 | IT 需要做什么 |
|------|-------------|
| 新员工入职 | 正常开通飞书账号即可，如果可用范围是"全部员工"则自动可用 |
| 员工离职 | 正常注销飞书账号即可，自动失去 Bot 访问权 |
| 修改可用范围 | 在「应用发布」→「版本管理」中创建新版本，修改可用范围 |
| 修改机器人名称/头像 | 在「凭证与基础信息」中修改 |
| 查看使用情况 | 在「数据统计」中查看消息量、活跃用户等 |

## 常见问题

**Q: 创建应用需要付费吗？**
A: 不需要。飞书开放平台的自建应用完全免费。

**Q: 需要备案域名或公网 IP 吗？**
A: 不需要。选择"长连接"模式即可，无需任何网络配置。

**Q: 应用创建后员工就能用了吗？**
A: 需要完成三个阶段（创建 + 启动服务 + 配置事件订阅 + 发布版本）后，员工才能搜索到机器人并对话。

**Q: 为什么配置事件订阅时保存失败？**
A: 飞书的"长连接"模式要求服务端已启动并连接。请确认部署者的日志中出现了 `Feishu WSClient connected`，然后再尝试保存。

**Q: 搜索到机器人但没有对话框？**
A: 最可能是事件订阅未配置或未包含在发布版本中。请回到步骤 6 确认事件订阅已保存，然后在步骤 7 创建新版本并发布。

**Q: 一个应用可以给多少人用？**
A: 企业方案中每人一个独立 Bot + 独立容器（见 enterprise-architecture.md）。每个 Bot 只有 1 条长连接（对应 1 个容器），不存在连接上限问题。

**Q: 以后需要更新应用吗？**
A: 通常不需要。凭证创建后长期有效，除非需要修改权限或可用范围。

**Q: 权限列表里还有 `im:message.p2p_msg:readonly` 等权限，需要开通吗？**
A: 不需要。`im:message` 已经包含了私聊消息的读取权限，无需额外开通子权限。
