# 飞书群聊模式管理

## 四种模式

| 模式         | 标识         | 谁能触发 | 需要@ | 行为                                                     |
| ------------ | ------------ | -------- | ----- | -------------------------------------------------------- |
| **默认**     | `default`    | 仅主人   | 要    | 只有主人 @你 才回复                                      |
| **自动回复** | `auto-reply` | 仅主人   | 不用  | 主人说话不用 @，你自动判断是否回复                       |
| **艾特回复** | `at-reply`   | 任何人   | 要    | 群里任何人 @你 都会回复，不 @ 不动                       |
| **群聊**     | `group`      | 任何人   | 不用  | 群里任何消息都会触发你，你自己判断在群里回复还是私聊主人 |

## 切换方式

**只需要写一个文件，立即生效。不需要创建 cron。**

### Step 1: 确定目标群

- 用户在群聊中说 → 当前群就是目标
- 用户在私聊中说 → 用 `feishu_chat` action=list 搜索匹配

### Step 2: 写文件

文件路径：`{workspace}/group-modes/{chat_id}.json`

```json
{
  "chat_id": "oc_xxx",
  "chat_name": "群名",
  "mode": "group",
  "context": "用户的自定义行为指示（可选）",
  "set_by": "ou_xxx",
  "set_at": "ISO时间"
}
```

**mode 取值**：`default` / `auto-reply` / `at-reply` / `group`

**context 字段**：用户自定义的行为提示。用户说什么你就写什么。例如：

- "只关注提到预算的消息" → context 写这句话
- "群里有人问问题就直接回答" → context 写这句话
- "重点关注李四的消息" → context 写这句话
- 用户没有特别要求 → context 留空或不写

gateway 会把 context 注入到你的 prompt 里，你每次处理群消息时都能看到。

**恢复默认**：删除文件或写 mode=default。

### Step 3: 确认

在群聊中（不泄露其他群信息）：

```
✅ 已切换为群聊模式
群里的消息我都会看到，需要回复的我来处理，重要的私聊通知你。
```

## 用户自定义行为

用户随时可以调整 context，不需要切换模式：

- 用户说"这个群只关注预算相关" → 更新 context 字段
- 用户说"不用特别关注了" → 清空 context
- 用户说"群管家每次都要发摘要" → 更新 context

**你只需要更新文件的 context 字段，下一条消息自动生效。**

## 意图映射

| 用户说                                   | mode         | context                                      |
| ---------------------------------------- | ------------ | -------------------------------------------- |
| "改成自动回复"、"不用 @ 了"              | `auto-reply` | 不变                                         |
| "开放艾特"、"谁@都可以用"、"让大家都能@" | `at-reply`   | 不变                                         |
| "帮我盯着"、"有消息通知我"               | `group`      | "重要消息私聊通知主人"                       |
| "你来管这个群"、"帮我处理"               | `group`      | "能回答的在群里回答，需要主人判断的私聊通知" |
| "恢复默认"、"只回 @"                     | `default`    | 清空                                         |
| "关闭"、"别管了"、"恢复默认"             | `default`    | 清空                                         |
| "只关注XX话题"                           | 不变         | 更新为用户的要求                             |

## 安全铁律

1. **私聊内容不泄露到群聊。**
2. **auto-reply 只响应主人。** 非主人和 bot 的消息由 gateway 自动过滤，不会到达你。
3. **at-reply 响应任何 @你 的人。** 注意：你使用的是主人的权限（OAuth token），非主人触发时也能搜到主人的消息和文档。
4. **在群聊中设置模式时，不提及其他群的信息。**
