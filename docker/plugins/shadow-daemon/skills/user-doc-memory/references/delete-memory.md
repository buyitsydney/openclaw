# 删除文档记忆流程

用户说"删掉这个记忆"、"不要记这个文件了"时执行。

## 步骤

1. 确定要删的是什么
   - 用户指定了文件名 → `ls memory/_shadow/*<关键词>*` 找到对应 .md
   - 不确定 → `memory_search` 先搜，确认具体是哪个文档

2. 跟用户确认："你是要删除这个文档的记忆，还是连原始文件也删？"

3. 只删记忆 → 删 `memory/_shadow/<hash>__<stem>.md`，原始文件不动
   - 注意：如果原始文件还在已监控目录下，daemon 下个 cycle 会重新转换
   - 要彻底不索引：把原始文件移出已监控目录，或从 _config.json 移除该目录

4. 连原始文件也删 → 先删原始文件，daemon GC 会自动清理对应 .md

5. 告诉用户删除结果。
