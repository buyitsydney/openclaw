# 索引文档流程

用户说"帮我索引/保存/记住这个文件"时执行。

## 步骤

1. 确定文件位置
   - 飞书发来 → `ls media/inbound/` 确认
   - 用户给了路径 → 确认文件存在
   - 不确定 → 问用户

2. 读 `_config.json`，确定目标目录
   - 有合适的已监控目录 → "我把它放到 docs/ 下？"
   - 没有 → "你想放到哪个目录？要不要新建一个？"
   - 等用户确认

3. 复制文件到目标目录
   - 目标目录不在 _config.json → 先添加进去

4. 告诉用户："文件已放入 {目录}，daemon 下个周期会自动转换。"
   - 用户急着用 → 进入 [manage-directories.md](manage-directories.md) 进度监控流程
