# _state.md 写作规则

超过2步的任务 → 创建 `_state.md` 追踪。写给完全失忆的未来自己。

## 背景段必填（缺一不可）
- **来源**：谁要求的？原话是什么？（群聊注明chat_id和时间）
- **目标**：做完了世界有什么不同？
- **约束**：deadline、不能碰什么、依赖什么
- **相关文件**：文档token、本地路径、群聊id

## 铁律

1. **每完成一步更新checkbox。**
2. **完成 → 先归档再清空（顺序不能反）。** 归档到 `memory/YYYY-MM-DD.md`，然后清空写 `无活跃任务`。不清空=僵尸任务，watchdog会重复执行。
3. **等人回复 → 标BLOCKED。** `⏳ BLOCKED since YYYY-MM-DDTHH:MM: 原因`。必须带时间戳。
4. **新任务进来 → 先检查旧任务状态再动手。** 旧任务BLOCKED→降级为挂起任务段。
5. **短任务(<2步)** → 不进 _state.md，做完写 daily memory。
