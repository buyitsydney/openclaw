# Twitter Monitor Skill

抓取指定 Twitter/X 账号的最新推文，整理成智能中文摘要后推送。

## 你的任务

给你一个 Twitter 用户名，你需要：

1. 拿到他**今天（CST 时区）**发布的所有推文（原创 + 转推 + 回复 + 引用）
2. 生成精简的中文智能摘要日报
3. 推送到指定渠道

**如果今天没有新推文** → 发一条 "📭 {账号名} 今日无新推文（最近一条发布于 {日期}）"，结束。

## 数据源

参考 `{baseDir}/references/sources.md` 了解已知可用/不可用的数据源和经验教训。

**你自己决定用什么方式抓取。** 可以用 browser、web_fetch、curl，甚至组合使用。目标是拿到数据，手段自选。

如果抓取过程中发现新的成功/失败经验，**更新 sources.md**，为下次积累。

## 输出格式（必须严格遵循！）

用户是 INTJ，要深度洞察不要信息堆砌。**必须分层**，不要平铺直叙所有推文：

1. **标题行**：🐦 {账号名} 推文日报 | {日期} | 今日 N 条
2. **🔥 重点推文**（2-3条展开）：只挑互动量最大或最有战略价值的
   - 完整摘要 + 互动数据 + **你的洞察分析**（为什么重要、对行业意味着什么）
   - 这是日报的核心价值，不是翻译而是分析
3. **📋 其余速览**：一行一条 `• HH:MM | 一句话概括 (💬X 🔁X ❤️X)`
   - 简洁！不展开，一行搞定
4. **💡 综合洞察**：对 Autolink/Her/AI 行业有价值的战略分析，1-3 句
   - 把今天所有推文串联起来，提炼出一个 narrative
5. **📡 底部**：数据源 + 抓取时间

**反面案例（不要这样做）**：把所有推文用相同篇幅平铺罗列，没有重点、没有分析、没有洞察。这是 RSS 阅读器，不是智能助手。

**正面案例（要这样做）**：2-3 条重点深度展开（含你的判断），其余一行速览，最后一段战略洞察把当天推文串成故事。

## 关键约束

- **只发送一条最终消息**，不要过程性输出
- 推文时间以 CST (UTC+8) 为准
- 重要图片下载后通过 message 工具的 filePath 发送
- 用你的智能做摘要，不要照搬原文翻译
